# El Tiempo de Irene

Reloj visual interactivo diseñado para ayudar a Irene a concentrarse y completar sus deberes, comidas y rutinas cotidianas de forma divertida (sin conexión externa, pensado especialmente para tablet Pixel y pantalla táctil).

## 🌐 Cómo usar la aplicación

Puedes abrirla directamente en el navegador (móvil, tablet o PC) usando **GitHub Pages**:

👉 **https://dbarreno-debug.github.io/el-tiempo-de-irene/**

### 📱 Ponerla como app en la tablet Pixel (Android / Chrome)
1. Abre el enlace de GitHub Pages en **Chrome** en la tablet.
2. Pulsa el menú de tres puntos (`⋮`) arriba a la derecha.
3. Toca **"Añadir a pantalla de inicio"** (o **"Instalar aplicación"**).
4. ¡Listo! Se abrirá a pantalla completa como una app más y guardará todas las estrellas, medallas, tareas y configuraciones en el dispositivo (`localStorage`).

### 💻 Usar en local sin internet
También puedes descargar el archivo [`index.html`](./index.html) y abrirlo directamente en cualquier navegador: es 100% autónomo (CSS y SVG integrados, sin dependencias externas).

## ✨ Características principales
- **Reloj visual estilo Time-Timer**: disco de color que se encoge suavemente (verde → naranja → rojo) para ver cuánto tiempo queda de un vistazo.
- **Misiones con pasos interactivos**: listas de deberes, comidas y tareas de casa con temporizador adaptable y rutinas encadenadas.
- **Compañeros SVG animados**: Misi Gatita, Kira Zorra, Nube Unicornio y Astro Cohete cambian de expresión según el progreso.
- **Estrellas, récords y álbum de 8 medallas**: sistema de recompensas canjeables en casa.
- **Modo tablet para padres**: botón de pantalla completa, *Wake Lock* (evita que la pantalla se apague mientras corre el reloj), avisos con campanas o voz en español, y candado matemático opcional para proteger ajustes y premios.
